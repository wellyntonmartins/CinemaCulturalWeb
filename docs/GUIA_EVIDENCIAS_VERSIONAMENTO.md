# Evidências de versionamento — Etapa 9

Este documento é um guia para registrar evidências reais depois de publicar o projeto. Não inclua capturas ilustrativas como se fossem resultados reais.

## Preparação do repositório

Crie um repositório novo no GitHub chamado `CinemaCulturalWeb` e envie a pasta do projeto. Na pasta do projeto, execute:

```bash
git init
git add .
git commit -m "Implementa backend e integracao da API"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/CinemaCulturalWeb.git
git push -u origin main
```

Se o repositório já tiver um README ou commit inicial, primeiro execute `git pull --rebase origin main` e resolva qualquer conflito antes do push. Não use `--force`.
